# MovieMania

A Django-based Movie Recommendation System.

## Features
- User registration and login
- Movie browsing
- Genre/preferences selection
- Movie recommendations
- Movie search/filtering
- Django Admin
- Database-backed movie management

## Technologies
- Python
- Django
- SQLite
- HTML
- CSS
- JavaScript
- Bootstrap

## How It Works
User
→ Selects preferences
→ Django processes preferences
→ Database is queried
→ Matching movies are retrieved
→ Recommendations are displayed
